# افغانستان قدیم — Unity Prototype 0.1

این مخزن برای نمونه اولیه بازی استراتژیک سه‌بعدی افغانستان قدیم است.

## تصمیم‌های طراحی
- گرافیک ترکیبی از واقع‌گرایی و فانتزی
- دوربین آزاد سه‌بعدی: حرکت، چرخش و زوم
- پلتفرم هدف: Android و iOS
- حالت آفلاین و آنلاین؛ قابلیت آنلاین هنوز ساخته نشده است
- آغاز بازی از دهکده کوچک و گسترش به امپراتوری
- الهام تاریخی از چند دوره افغانستان، نه بازسازی دقیق یک دوره واحد

## راه‌اندازی در Unity
1. با Unity Hub پروژه 3D (URP) در Unity 6 بسازید.
2. پوشه Assets این مخزن را داخل پروژه کپی کنید.
3. در Unity از منوی Ancient Afghanistan و سپس Create Prototype Scene استفاده کنید.
4. صحنه Assets/Scenes/AncientAfghanistan_Prototype.unity را باز کنید و Play بزنید.
5. در Player Settings گزینه Active Input Handling را روی Both یا Input Manager (Old) قرار دهید.

## کنترل‌ها
- WASD یا کلیدهای جهت: حرکت دوربین
- راست‌کلیک و کشیدن: چرخش
- چرخ ماوس: زوم
- B: فعال یا غیرفعال کردن ساخت
- 1 خانه، 2 انبار، 3 سربازخانه
- کلیک چپ روی زمین: قرار دادن ساختمان

## موجود در نسخه 0.1
- محیط موقت دهکده، قصر، خانه، انبار، مزرعه و سربازخانه
- رودخانه، جاده، تپه و درخت
- دوربین آزاد و سیستم ابتدایی جای‌گذاری ساختمان

## هنوز پیاده‌سازی نشده
مدل‌های نهایی هنری، شخصیت و انیمیشن، اقتصاد واقعی، سربازان و نبرد، ذخیره پیشرفت، کنترل لمسی نهایی، حساب کاربری، سرور و جنگ آنلاین، خروجی APK و IPA.

این نسخه prototype است و برای انتشار عمومی آماده نیست.
