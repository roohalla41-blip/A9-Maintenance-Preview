# افغانستان قدیم — نمونه اولیه Unity 0.2

این شاخه یک نمونه اولیه قابل توسعه برای بازی استراتژیک سه‌بعدی «افغانستان قدیم» است. هدف نهایی، ساخت یک بازی جذاب امپراتوری‌سازی برای Android و iOS است.

## تصمیم‌های طراحی
- گرافیک ترکیبی از واقع‌گرایی و فانتزی
- دوربین آزاد سه‌بعدی؛ حرکت، چرخش و زوم
- پلتفرم هدف: Android و iOS
- شروع از یک دهکده کوچک و گسترش تدریجی به امپراتوری
- الهام از چند دوره تاریخی افغانستان، نه بازسازی دقیق یک دوره واحد
- نسخه نخست به‌صورت آفلاین طراحی می‌شود؛ آنلاین هنوز ساخته نشده است

## راه‌اندازی در Unity
1. با Unity Hub نسخه دقیق Unity `2022.3.62f1` را نصب کنید و ماژول‌های Android Build Support، Android SDK & NDK Tools و OpenJDK را فعال کنید. فایل `ProjectSettings/ProjectVersion.txt` نسخه پروژه را مشخص می‌کند.
2. مخزن را به‌عنوان پروژه Unity باز کنید؛ پوشه‌های `Assets`، `Packages` و `ProjectSettings` از قبل در آن قرار دارند.
3. صحنه نمونه در اولین بازشدن Editor یا هنگام ساخت APK به‌صورت خودکار ایجاد می‌شود.
4. صحنه Assets/Scenes/AncientAfghanistan_Prototype.unity را باز کنید و Play بزنید.
5. برای اجرای محلی، در Player Settings گزینه Active Input Handling را روی Both یا Input Manager (Old) قرار دهید. خروجی خودکار Android از Workflow مخصوص Unity در شاخه `feature/gameplay-foundation` ساخته می‌شود و به Secret معتبر `UNITY_LICENSE` نیاز دارد.

## کنترل‌ها
- رایانه: WASD یا کلیدهای جهت برای حرکت دوربین
- رایانه: راست‌کلیک و کشیدن برای چرخش؛ چرخ ماوس برای زوم
- موبایل: کشیدن یک انگشت برای چرخش؛ دو انگشت برای زوم
- B: روشن/خاموش کردن حالت ساخت
- 1 خانه، 2 انبار، 3 سربازخانه، 4 برج نگهبانی، 5 دیوار دفاعی
- کلیک چپ روی زمین: ساخت ساختمان انتخاب‌شده
- دکمه‌های روی صفحه برای جمع‌آوری چوب، سنگ و غذا

## امکانات نمونه اولیه 0.2
- محیط موقت دهکده با رودخانه، جاده، تپه، درخت، مزرعه، خانه، قصر، انبار و سربازخانه
- دوربین آزاد با ژست‌های لمسی ابتدایی
- مردم دهکده و نگهبانانی که در محیط حرکت می‌کنند
- منابع ابتدایی چوب، سنگ و غذا
- تولید خودکار محدود منابع در گذر زمان
- ساخت خانه، انبار و سربازخانه با هزینه منابع
- حمله دوره‌ای مهاجمان، دفاع خودکار نگهبانان و آموزش نگهبان تازه
- برج نگهبانی با حمله خودکار به مهاجمان نزدیک
- ساخت دیوارهای دفاعی ساده

## محدودیت‌ها و کارهای بعدی
- شکل مردم و ساختمان‌ها فعلاً با اشکال ساده Unity ساخته شده؛ مدل و انیمیشن نهایی نیست.
- نبرد و برج نگهبانی فعلاً نمونه ابتدایی‌اند؛ مسیر‌یابی، انیمیشن، تخریب دیوار و توازن جنگ هنوز لازم است.
- مأموریت‌ها، فناوری‌ها، تجارت و دیپلماسی هنوز ساخته نشده‌اند.
- ذخیره محلی و کنترل لمسی در مرحله ابتدایی پیاده‌سازی‌اند و هنوز باید در Editor و روی گوشی واقعی آزموده و تکمیل شوند.
- کنترل کیفیت گرافیک هنگام شروع بازی به‌صورت خودکار اضافه می‌شود؛ در نبود فایل‌های پروفایل نیز بر اساس حافظه و توان دستگاه، سطح پایین/متعادل/بالا را انتخاب می‌کند. این تنظیمات هنوز در Unity Editor و روی گوشی واقعی آزمایش نشده‌اند.
- حالت آنلاین و سرور هنوز ساخته نشده است.
- خروجی APK واقعی Unity هنوز به‌دلیل نبود مجوز Unity در GitHub Actions ساخته نشده است؛ IPA نیز هنوز پیکربندی یا ساخته نشده است.

این کدها در GitHub ثبت شده‌اند، اما هنوز داخل Unity Editor کامپایل و Playtest نشده‌اند؛ بنابراین فعلاً نباید آن را نسخه آماده نصب یا انتشار دانست.
